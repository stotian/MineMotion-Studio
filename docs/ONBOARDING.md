# Onboarding

The first-launch experience provides five real entry points: production templates, recent projects, the native/browser open workflow, autosave recovery, and quick-start help. Progress is optional, stored locally, and never blocks expert users.

The guided path is: choose a template, frame the viewport, scrub the timeline, add a keyframe, verify Render Preview, then validate and export. The guide uses existing editor actions rather than simulated controls.

Reset the guide by removing the `minemotion.onboarding.v1` local-storage entry. No analytics or project data leave the device.
