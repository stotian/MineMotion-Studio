# Accessibility

Primary workflows support keyboard focus, visible focus rings, semantic dialogs, status announcements, UI/text scaling, reduced motion, high contrast, and color-vision modes. Markers and diagnostics use labels and icons in addition to color.

Shortcut remapping is not part of the v1 MVP. The current fixed shortcuts are searchable in Help and the command palette; conflicts are tested. This limitation is explicit rather than presenting a non-functional customization screen.

Manual QA must cover keyboard-only project creation, object selection, timeline navigation, settings, recovery, validation, and export at 100%, 125%, 150%, and 200% display scaling.
