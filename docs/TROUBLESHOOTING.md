# Troubleshooting

- **Project will not open:** preserve the file, export diagnostics, and test a duplicate. CRC, size and schema errors are intentionally blocking.
- **Recovery appears:** restore to inspect it, then save under a new name. Discard only when the autosave is not needed.
- **Extensions are inactive:** check global plugin enablement, safe mode, compatibility, dependencies, trust and requested permissions.
- **FFmpeg export is unavailable:** use the desktop build, verify the executable and output folder, then run codec detection. Cancellation may leave no final output by design.
- **Reduced performance:** inspect viewport recommendations and reduce world radius, VFX count or preview quality; optimization suggestions never modify the project automatically.
