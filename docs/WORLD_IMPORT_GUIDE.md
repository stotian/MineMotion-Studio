# World import guide

Select a read-only Java world source, choose a dimension and bounded region by
spawn, coordinates, radius, regions or chunks, inspect the top-down preview and
cost estimate, then import. Save profiles for repeatable selections. Reimport
changed chunks or unload regions without modifying the source world.

A project may embed a compact portable chunk cache or save a source-reference
workflow. Missing/corrupt caches reopen with warnings. Old pre-flattening worlds,
entities, block entities, structures, arbitrary mod renderers and ZIP64 resource
packs are outside the current guarantee.
