# World compatibility matrix

| Family | Status |
|---|---|
| Java modern Anvil 1.18+ fixtures | Supported by importer tests |
| Java flattened Anvil 1.13–1.17 | Partial; palette/biome variations require fixtures |
| Java custom dimensions | Supported by directory discovery |
| Java pre-flattening numeric IDs | Unsupported as a complete mapping |
| Bedrock LevelDB worlds | Unsupported |
| Arbitrary mod renderers | Partial fallback only; no imported code execution |
