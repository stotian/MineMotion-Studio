# Export guide

Validate project state, camera, range, assets, VFX dependencies, plugins,
resource pack, resolution, FPS, audio, format and disk estimate before queueing.
The Production workspace can queue one active take or all active shots with
beauty, alpha, world, characters, VFX, depth and object-ID passes.

Browser mode supports its documented PNG/sequence/WebM/WAV paths. Native mode
can use a user-selected FFmpeg executable through allowlisted arguments and a
cancellable job registry. Handoff metadata includes deterministic paths,
numbered frames, FPS, timecode and audio information. EDL/XML is not promised.
