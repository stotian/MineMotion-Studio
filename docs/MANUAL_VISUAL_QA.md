# Manual visual QA checklist

## Display and input
- [ ] 1920×1080 at 100% scaling
- [ ] 2560×1440 at 125% scaling
- [ ] small window at 1280×720
- [ ] keyboard-only navigation with visible focus
- [ ] reduced motion, high contrast, and each color-vision mode

## Primary workflows
- [ ] first launch, template, recent project, open, recovery, help
- [ ] viewport selection, orbit, camera view, overlays
- [ ] timeline scrub, markers, keyframes, clips, playback
- [ ] rig, VFX, world import, lighting, audio, production shots
- [ ] Render Preview and all advertised passes
- [ ] save, reopen, migration, missing asset, recovery
- [ ] PNG, sequence, WAV, WebM/FFmpeg where available

Record platform, GPU, display scale, project, commit, result, and screenshots only when reproducible from a named sample.
