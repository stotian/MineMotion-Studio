# Quick start

1. Create or open a `.minemotion` project.
2. Add a Steve/Alex character, camera, world region, or imported asset.
3. Animate objects and rigs on the timeline; use Lighting Studio and VFX Studio
   for atmosphere and effects.
4. Open Production to create shots, takes, storyboard notes and render passes.
5. Validate the shot, queue it, then export frames/audio/video through the
   available browser or native workflow.
6. Save frequently. Startup recovery can restore bounded autosave snapshots.

Experimental procedural crowds appear only when their feature flag is enabled.

## Template-to-export workflow

1. Choose a **template** from the first-launch screen or Project menu.
2. Select the active camera and frame the subject in the viewport.
3. Move the timeline cursor, change a transform, and add a **keyframe**.
4. Preview the shot, review markers and warnings, then open Export.
5. Save a `.minemotion` package before starting a long render.
