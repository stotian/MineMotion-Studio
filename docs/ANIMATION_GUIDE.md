# Animation guide

The timeline, Dopesheet, Graph Editor and NLA views edit the same canonical
project tracks. Use key selection, snapping, interpolation, clips, layers,
markers, IK, look-at, foot locks, procedural generators and pose tools without
creating a second animation store.

Production shots reference frame ranges and cameras; they do not replace the
animation timeline. Preview Shot stops at the shot end. Duplicate a shot as a
new take to preserve earlier revisions.
